## 🚀 Архитектура и характеристики

- **Протокол:** WireGuard (работает в пространстве ядра Linux, ChaCha20-Poly1305, Curve25519).
- **Базовая ОС:** Debian 12 (Bookworm) или Ubuntu 22.04 / 24.04 LTS.
- **Интерфейс администратора:** `wg-easy` в легковесном Docker-контейнере (потребление RAM ~45 МБ).
- **Сетевая оптимизация:** Google BBR Congestion Control, MTU 1420, PersistentKeepalive 25 сек (стабильная работа в сетях мобильных операторов).
- **Потребление ресурсов:**
  - ОЗУ: ~120 МБ суммарно (ОС + Docker + wg-easy), свободно > 850 МБ.
  - Нагрузка на процессор: < 5% при 15 активных клиентах на 1 vCPU.

## ⚡ Быстрый старт за 5 минут

### Шаг 1. Аренда VPS
Подойдет любой хостинг (Hetzner, Aeza, Vdsina, Timeweb Cloud, DigitalOcean, Scaleway):
- **Тариф:** 1 vCPU, 1 GB RAM, 10–20 GB SSD.
- **ОС:** `Debian 12` (рекомендуется) или `Ubuntu 22.04 LTS`.
- **Локация:** Нидерланды, Германия, Финляндия или Турция (в зависимости от ваших задач).

### Шаг 2. Подключение к серверу
```bash
ssh root@<IP_ВАШЕГО_СЕРВЕРА>
```

### Шаг 3. Клонирование и запуск скрипта развертывания
Выполните одну цепочку команд:
```bash
apt-get update && apt-get install -y git
git clone https://github.com/tuloAminov/taga_vpn.git /opt/vpn_taga || mkdir -p /opt/vpn_taga
cd /opt/vpn_taga
```
*(Или просто скопируйте файлы `docker-compose.yml` и `setup.sh` на сервер)*.

Сделайте скрипт исполняемым и запустите его:
```bash
chmod +x setup.sh
./setup.sh
```

**Скрипт автоматически:**
1. Определит внешний IP сервера.
2. Создаст файл подкачки (Swap) на 1.5 ГБ (защита от падений по OOM).
3. Включит IP Forwarding и алгоритм BBR в ядре Linux.
4. Установит Docker и Docker Compose.
5. Настроит межсетевой экран UFW (разрешит только SSH, 51820/UDP и 51821/TCP).
6. Запустит WireGuard и панель управления.

В конце работы скрипт выведет ссылку на панель управления и сгенерированный пароль:
```text
Адрес панели управления:  http://198.51.100.25:51821
Пароль администратора:    a8F9k2Lm90Qx...
```

## 🖥️ Управление пользователями через Web UI

1. Откройте в браузере: `http://<IP_СЕРВЕРА>:51821`
2. Введите ваш пароль администратора.
3. **Добавление пользователя:**
   - Нажмите **"+ New Client"**.
   - Укажите имя (например: `dad-iphone`, `brother-laptop`).
   - Нажмите **"Create"**.
4. **Выдача конфигурации:**
   - **Для смартфонов:** Нажмите на иконку **QR-кода** рядом с именем пользователя.
    - **Для ПК / ноутбуков:** Нажмите **"Download"** и передайте скачанный `.conf` файл пользователю в мессенджере.
5. **Отзыв доступа:**
    - Для временной блокировки: переключите тумблер в положение OFF.
    - Для окончательного удаления: нажмите иконку корзины.

## 🌐 Раздельное туннелирование: Ozon, WB, VK и банки без выключения VPN

Многие российские сервисы (Ozon, Wildberries, Госуслуги, VK, Сбер, Т-Банк) защищаются от DDoS и блокируют IP-адреса зарубежных дата-центров.

Чтобы **вашим родным и друзьям не приходилось ничего настраивать вручную** и постоянно выключать VPN, используется раздельное туннелирование (Split-Tunneling). Вы передаете им готовый `.conf` файл:
- Все российские IP-диапазоны автоматически идут **напрямую** через их домашнего провайдера на максимальной скорости.
- Telegram, YouTube, Instagram, Twitter, ChatGPT и весь зарубежный трафик идут **через VPN**.

### Вариант 1. Генерация на Windows (без захода на сервер)
Если вы скачали `.conf` файл пользователя из веб-панели на свой ПК:
1. Запустите в терминале:
   ```powershell
   # Оптимизированный режим (по умолчанию, коннект ~0.8 сек):
   .\make-split-config.ps1 "C:\Users\...\Downloads\mama.conf"

   # Ультрабыстрый режим (коннект < 0.2 сек, мгновенно):
   .\make-split-config.ps1 "C:\Users\...\Downloads\mama.conf" instant
   ```
   *(Или запустите `.\make-split-config.ps1` и просто перетащите файл мышкой в окно)*.
2. Скрипт создаст файл `mama_split.conf` (или `mama_instant.conf`).
3. Отправьте файл маме в Telegram или WhatsApp.

### Вариант 2. Генерация на сервере (Linux / VPS)
В репозитории есть готовые утилиты для сервера:
- **Конвертировать существующего клиента:**
  ```bash
  # Оптимизированный режим (fast, коннект ~0.8 сек):
  ./make-split-config.sh mama

  # Ультрабыстрый режим (instant, коннект мгновенный < 0.2 сек):
  ./make-split-config.sh mama instant

  # Или для всех клиентов сразу:
  ./make-split-config.sh all instant
  ```
- **При использовании `native-wg.sh`:**
  ```bash
  ./native-wg.sh add-split mama
  ```
  Скрипт сразу создаст клиента и сгенерирует готовый `mama_split.conf`.

### ⚡ Подробное сравнение режимов: `fast` vs `instant` vs `full`

| Параметр | 🚀 Оптимизированный (`fast`, по умолчанию) | ⚡ Мгновенный (`instant`, ультрабыстрый) | 🐢 Полный (`full`) |
| :--- | :--- | :--- | :--- |
| **Логика работы** | **Исключение РФ (Blacklist):** Весь интернет мира идет в VPN, а сайты РФ исключены | **Точечный проброс (Whitelist):** В VPN идут только конкретно заблокированные сервисы | Точное исключение 21 000 сетей РФ без округления |
| **Маршрутов в AllowedIPs** | **~2 100 подсетей** | **~100–150 подсетей** | 21 700+ подсетей |
| **Скорость включения** | **~0.7 – 1.0 сек** | **< 0.15 сек (мгновенно)** | ~5 – 10 сек (может подвисать) |
| **Telegram** | **В VPN** (все DC, звонки, медиа) | **В VPN** (все DC, звонки, медиа) | **В VPN** |
| **YouTube, Instagram, X, Discord, ChatGPT** | **В VPN** | **В VPN** | **В VPN** |
| **Любые другие зарубежные сайты, игры, Spotify, GitHub, Netflix** | **В VPN** (открывается абсолютно всё зарубежное) | **Напрямую** (если домен/IP не в выгрузке РКН) | **В VPN** |
| **Банки РФ, Госуслуги, Ozon, WB, Яндекс, VK** | **Напрямую** (без капчи, полная скорость провайдера) | **Напрямую** (без капчи, полная скорость провайдера) | **Напрямую** |
| **Нагрузка на процессор / ОЗУ смартфона** | Незаметна на любых современных устройствах | Нулевая (даже на древних телефонах за $50) | Заметна (ОС долго прописывает 21k маршрутов) |
| **Для кого идеален** | **Основной выбор для себя и близких:** получаете полноценный открытый интернет без блокировок, при этом российские сервисы не ругаются на заграничный IP. | **Для родителей, бабушек и слабых устройств:** идеален, когда от VPN нужны только YouTube, Telegram, Instagram и WhatsApp с мгновенным откликом тумблера. | Резервный технический режим. |

## 📱 Инструкция для конечных пользователей (для родных)

### Подключение через Split-файл (Рекомендуется — работает Ozon, WB и банки):
1. Установите приложение **WireGuard**:
   - [App Store (iOS)](https://apps.apple.com/app/wireguard/id1441195209)
   - [Google Play (Android)](https://play.google.com/store/apps/details?id=com.wireguard.android)
2. В Telegram/WhatsApp нажмите на полученный файл `..._split.conf`.
3. Нажмите кнопку **«Поделиться»** -> выберите **WireGuard** (или в WireGuard: «+» -> «Создать из файла или архива»).
4. Включите тумблер. Больше ничего настраивать не нужно!

## 🔒 Безопасность и файрвол

### Файрвол (UFW)
Скрипт по умолчанию настраивает жесткие правила UFW:
- `22/tcp` — SSH доступ.
- `51820/udp` — WireGuard туннель (защищен асимметричной криптографией Noise/Curve25519).
- `51821/tcp` — Web-интерфейс администратора.

### Максимальный уровень паранойи (Скрытие Web UI из интернета)
Если вы хотите, чтобы порт веб-панели `51821` **вообще не был виден снаружи**:
1. Закройте порт в UFW:
   ```bash
   ufw delete allow 51821/tcp
   ```
2. Подключайтесь к веб-панели через безопасный SSH-туннель с вашего ПК:
   ```bash
   ssh -L 51821:127.0.0.1:51821 root@<IP_СЕРВЕРА>
   ```
3. После этого панель будет открываться в вашем локальном браузере по адресу:
   `http://localhost:51821`

## 🛠️ Альтернатива: Управление через CLI без Docker

Если вы принципиально не хотите использовать Docker и стремитесь к минимальному потреблению ресурсов (~15 МБ RAM):
В репозитории есть готовый скрипт `native-wg.sh`.

```bash
# Инициализация сервера
chmod +x native-wg.sh
./native-wg.sh init

# Создание нового пользователя и генерация QR-кода прямо в консоли
./native-wg.sh add ivan-phone

# Просмотр подключенных клиентов и переданного трафика
./native-wg.sh list

# Удаление пользователя
./native-wg.sh remove ivan-phone
```

## 💾 Резервное копирование и восстановление

Все ключи, настройки пиров и база клиентов хранятся в одной директории `./data`:

### Создание бэкапа
```bash
cd /opt/vpn_taga
tar -czvf vpn_backup_$(date +%F).tar.gz data/ .env docker-compose.yml
```

### Восстановление на новом сервере
1. Установите Docker на новый сервер.
2. Скопируйте архив и распакуйте:
   ```bash
   tar -xzvf vpn_backup_*.tar.gz -C /opt/vpn_taga/
   cd /opt/vpn_taga
   docker compose up -d
   ```
Все ваши друзья и родственники подключатся автоматически без необходимости перевыпускать файлы!

## ❓ Устранение неполадок

- **Трафик не идет (нет интернета после подключения):**
  Проверьте включен ли IP Forwarding:
  ```bash
  sysctl net.ipv4.ip_forward
  # Должно быть: net.ipv4.ip_forward = 1
  ```
- **Служба не стартует:**
  Проверьте статус контейнера:
  ```bash
  docker compose ps
  docker compose logs -f
  ```
- **Забыли пароль от веб-панели:**
  Откройте `.env` файл на сервере:
  ```bash
  cat /opt/vpn_taga/.env
  ```
